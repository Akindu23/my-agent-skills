# Remove-slop edit

Caller named classes → only those hits. Else every Scan hit.

## 1. Edit

Smallest edit that restores grain. Code keeps behavior unless a clear bug. Prose keeps meaning. Leave neighbors and older slop.

A `MUST KILL` hit: delete the confession, or keep the suppression when no local fix exists. The flagged symbol stays as written; its refactor is the user's call.

**Done when**: every in-scope hit is edited, or skipped because it *is* this file's grain.

## 2. Audit

Ask: *what still makes this obviously generated?* Fix remaining slop. Then 1-3 sentences to the user, plus one `MUST KILL <symbol> - path:line - why` line per flag.

**Done when**: that question has an answer, remaining slop is gone, the summary is 1-3 sentences, and every flag has its line.
